# Pulsar

基于原版 Pulsar，加入了 **GD音乐台集成**，支持歌曲搜索、播放和队列，沿用原有音乐同步功能。

扩展版标识：`0.0.3.1-gd.1`，卫月安装版本仍为 `0.0.3.1`。

GitHub 仓库：https://github.com/WayuSama/Pulsar

在卫月的「自定义插件仓库」中添加：

```text
https://raw.githubusercontent.com/WayuSama/dalamud-plugins/main/pluginmaster.json
```

安装后输入 `/pulsar`，在 SOURCE 中选择「GD音乐台」。
