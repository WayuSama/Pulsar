# Pulsar

纯vibe写的

基于原版 Pulsar，加入了 **GD音乐台集成**，支持歌曲搜索、播放和队列，沿用原有音乐同步功能。


版本：`0.0.3.102`（基于原版 `0.0.3.1`，修改序号 `02`）。发布版本与卫月安装版本一致。

版本号最后一段为「原版第四段 × 100 + 修改序号」，修改序号为 `1–99`。

GitHub 仓库：https://github.com/WayuSama/Pulsar

在卫月的「自定义插件仓库」中添加：

```text
https://raw.githubusercontent.com/WayuSama/dalamud-plugins/refs/heads/main/pluginmaster.json
```

安装后输入 `/pulsar`，在 SOURCE 中选择「GD音乐台」。
